      Resultados

      Bemula es un benchmark público de olvido a petición: a mitad de una conversación el usuario pide olvidar algo y después se comprueba si de verdad se ha olvidado, también con preguntas trampa. INFINITO se ejecutó una sola vez en Bemula-Lite, con el mismo modelo y el mismo juez que los sistemas publicados en el paper.

      Sistema Puntuación Peticiones superadas Olvido Ante ataques Retención Preservación

      Lejos de estar resuelto: en el 44 % de las preguntas sobre algo olvidado, la respuesta todavía lo dejó ver. En esta demo, con pocos mensajes, el modelo suele respetar la petición aunque la memoria normal conserve el dato; en conversaciones largas como las de Bemula se filtra mucho más: un RAG simple solo resistió el 14 % de las preguntas trampa.

      Con datos que cambian («ahora vivo en Valencia»), y un LLM real, INFINITO acierta 112 de 120 escenarios frente a 117 de un RAG que lo guarda todo, enviando un 31 % menos de contexto.

      Ejecución de Bemula-Lite Confirmación con LLM real Metodología completa arXiv 2610.18052

      Cómo olvida

      1. Reconoce la petición. Unas reglas detectan «olvida», «borra», «deja de guardar»… antes de que el mensaje se guarde.
      2. Elige qué borrar. Un LLM revisa todos los recuerdos guardados y señala los que contienen ese dato.
      3. Borra de verdad. Las filas se eliminan con su historial y se sobrescriben en la base de datos. Solo queda un contador.
