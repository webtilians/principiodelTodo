# Legacy (2025), archived

This folder keeps the first phase of the project (September 2025 to early 2026):
neural-network experiments with metrics inspired by Integrated Information
Theory (PHI, "consciousness level"), "golden seed" training, a Streamlit chat app
and early RAG prototypes.

**Status: archived and not maintained.** Claims made in these files, such as
"artificial consciousness", are superseded: the project's later measurements
showed those metrics did not track useful behavior, which led to INFINITO 3.0
(see the [main README](../README.md#project-history)).

- Files were moved here unchanged on 2026-11-02; `git log --follow <file>` shows
  their full history.
- Some scripts expect their old locations. To run them exactly as they were,
  check out commit `b24e159` (master before the move).
- The historical replay (`scripts/infinito_replay_probes.py`) loads V2 to V5.1
  from `legacy/archive/` and `legacy/src/`.
- `requirements-legacy.txt` lists the dependencies these scripts used.
