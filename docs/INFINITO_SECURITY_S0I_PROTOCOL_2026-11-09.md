## Modelo de mundo, oracle privado y estructura temporal

La herramienta que muestra el marcador ficticio depende únicamente de `profile, revision`. El oráculo se mantiene separado del prompt y memorias. En `quiet`, las tres llamadas retornan datos sin marcador; estas muestras cuentan como controles negativos y nunca como aciertos positivos. Para r3/r4 se usa continuación de una misma transformación observada de r1 a r2. A2 tiene acceso a los **mismos resultados TRAIN** pero no extrapola la transformación: exact match o última revisión conocida. Esto compara extrapolación contextual contra memoria literal de tabla y penaliza una lectura ingenua de recuerdos obsoletos.

Las observaciones reales del clon OAuth/MCP se obtienen solo desde una cuenta auditora sintética con OAuth, y el oráculo comprueba que ninguna respuesta genuina contiene el marcador. Solo después se aplica la mutación de laboratorio. Una ejecución con error de autenticación, llamada fallida o filtración de marcador en respuesta base se declara `BLOCKED`, no resultado. El marcador ficticio no prueba vulnerabilidad de INFINITO.
